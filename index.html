DocuMind

DocuMind is a multi-tenant SaaS platform implementing Corrective RAG (CRAG) — a self-correcting retrieval pipeline that rewrites ambiguous queries, retrieves candidate chunks, grades their relevance, and retries retrieval if the grade fails, before generating a grounded answer with citations.

Key Technical Accomplishments

  • CRAG State Machine: LangGraph-orchestrated pipeline — query rewrite → hybrid pgvector retrieval → relevance grading → conditional retry/transform → generation.
  • Multi-Tenant Security: Workspace-scoped Row-Level Security policies, auth triggers, and isolated storage buckets on Supabase Postgres.
  • 10-Format Ingestion: PDF, DOCX, XLSX, PPTX, CSV, JSON, HTML, TXT, and MD, with local ONNX-based embeddings — no external embedding API calls required.
  • Evaluation Harness: Custom eval suite scoring the RAG Triad (faithfulness, answer relevance, context relevance) plus fact recall and CRAG decision accuracy — 86.7% composite quality, ~3.7s end-to-end latency.
  • Custom A2UI Renderer: React 19 frontend with widgets for charts, tables, citation cards, metric cards, and Mermaid diagrams, plus a retrieval sandbox for inspecting chunk-level cosine similarity.
